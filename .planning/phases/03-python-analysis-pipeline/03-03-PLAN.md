2. extract(parsed_demo: ParsedDemo) -> FeatureResult method:

   Implementation steps (per FEAT-03 and RESEARCH.md with concrete mathematical specifications):
   
   a. Kill detection: Find all player_death events where attacker is a player (shooter)
      - Filter events_df where event_type == "player_death"
      - For each death, find the kill_tick (use the tick of death event)
      - Validate at least 1 kill exists, else raise FeatureExtractionError("insufficient_kills")

   b. Snap ratio calculation (measure of aim adjustment magnitude):
      - Kill window: 10 ticks before kill_tick to kill_tick
      - Extract yaw values (horizontal aim angle) in this window
      - Compute absolute yaw delta per tick: |yaw[i] - yaw[i-1]|
      - snap_ratio for this kill = max(|yaw[i] - yaw[i-1]|) / mean(|yaw[i] - yaw[i-1]|) + epsilon
      - Collect snap_ratio values across all kills
      - Normalize: mean_snap = np.mean(snap_ratio_values)
      - Use sigmoid_normalize(mean_snap, inflection_point=1.0, scale=2.0)
      - Reference: mean_snap > 1.5 maps to ~0.73; mean_snap > 2.0 maps to ~0.88

   c. Angular velocity calculation (rate of aim change):
      - For each kill window, compute: angular_velocity = (max(yaw) - min(yaw)) / window_size_ticks
      - Collect across all kills, measure mean
      - Threshold: 90 deg/tick is human physical limit
      - Normalize: use sigmoid_normalize(mean_av, inflection_point=90, scale=1/45)

   d. Angular jerk calculation (acceleration of aim):
      - Angular jerk = d(angular_velocity)/dt = second derivative of yaw
      - Compute as: (velocity[i] - velocity[i-1]) / dt
      - Threshold: > 2 deg/tick² is suspicious (mechanical aimbot characteristic)
      - Normalize: use sigmoid_normalize(max_jerk, inflection_point=2, scale=0.5)

   e. Reaction proxy calculation (time from player noise to aim adjustment):
      - For each kill, find if there was audible (footstep) event before kill
      - Measure ticks between last footstep and snap detection
      - Threshold: < 50ms (~3-5 ticks at 64 ticks/sec) is suspicious
      - Normalize: use sigmoid_normalize(median_reaction_ticks, inflection_point=3, scale=0.3)

   f. Score combination (per checker requirement):
      - Sub-scores: [norm_snap, norm_av, norm_jerk, norm_reaction]
      - final_score = max(norm_snap, norm_av, norm_jerk) [conservative: any high sub-score indicates aimbot]
      - Validate with _validate_score()

   g. Return FeatureResult:
      - score: final_score (float [0.0, 1.0])
      - raw_measurements: {
          "kills_detected": len(kills),
          "snap_ratio_values": snap_ratio_values,
          "mean_snap_ratio": mean_snap,
          "normalized_snap": norm_snap,
          "angular_velocity_values": angular_velocity_values,
          "mean_angular_velocity": mean_av,
          "normalized_av": norm_av,
          "angular_jerk_max": max_jerk,
          "normalized_jerk": norm_jerk,
          "reaction_proxy_median": reaction_proxy_median,
          "normalized_reaction": norm_reaction,
        }
      - metadata: {
          "method": "aimbot_multifeature_sigmoid",
          "version": "1.0",
          "warnings": [...] (e.g., if snap ratio distribution is bimodal)
        }

3. Quality requirements:
