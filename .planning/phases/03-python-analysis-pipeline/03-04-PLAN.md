   Implementation steps (per FEAT-06 with concrete mathematical specifications):

   a. Weapon fire event extraction:
      - Filter events_df for event_type == "weapon_fire"
      - Group by weapon_name (extract from ticks_df active_weapon_name)
      - Validate at least 10 weapon fire events (sprays) exist, else raise FeatureExtractionError("insufficient_sprays")

   b. Spray sequence extraction (per checker requirement):
      - For each weapon fire event, extract successive ticks where is_shooting == True
      - Spray window: from first to last shot in continuous burst (max 50 ticks)
      - Build spray sequence: [(yaw_delta, pitch_delta), ...]
      - Spray coordinate conversion (per checker requirement): yaw_delta * sensitivity_px_per_deg, pitch_delta * sensitivity_px_per_deg
      - Assume sensitivity=1.0 (pixel per degree) for baseline; can be tuned per player config
      - Extract spray as list of [x, y] pixel coordinates matching pattern format

   c. Pattern correlation (per checker requirement):
      - For each spray sequence, find matching pattern from self.patterns
      - Correlation method: scipy.stats.pearsonr(extracted_spray, pattern_spray_points)
      - Correlation threshold: > 0.7 = likely compensated recoil (suspicious)
      - Store correlation per spray
      - Normalize: use sigmoid_normalize(mean_correlation, inflection_point=0.5, scale=2.0)

      - If multiple sprays with same weapon, compute variance of correlations
      - Consistency variance: var(correlation_values)
      - Consistency threshold: variance < 0.1 = mechanically consistent (bot-like)
      - Score: if multiple sprays same weapon, variance / 0.3 (normalize to 0-1)

   e. Score combination (per checker requirement):
      - mean_correlation: average of all spray correlations
      - consistency_score: 1 - (variance / 0.3)  [normalize variance to 0-1]
      - final_score = 0.6 * sigmoid_normalize(mean_correlation, inflection_point=0.5, scale=2.0) + 0.4 * (1 - variance/0.3)
      - Validate with _validate_score()

   f. Return FeatureResult:
      - score: final_score [0.0, 1.0]
      - raw_measurements: {
          "sprays_detected": num_sprays,
          "spray_window_max_ticks": 50,
          "mean_correlation": mean_correlation,
          "correlation_values": [corr1, corr2, ...],
          "correlation_threshold": 0.7,
          "consistency_variance": variance,
          "consistency_normalized": consistency_score,
          "weapons_used": list(unique_weapons),
          "sensitivity_px_per_deg": 1.0,

          "method": "recoil_correlation_sigmoid",
          "version": "1.0",

          "correlation_formula": "scipy.stats.pearsonr(extracted_spray, pattern)",

2. extract(parsed_demo: ParsedDemo) -> FeatureResult method:

   Implementation steps (per FEAT-07 with concrete mathematical specifications):

   a. Jump-land event pairing:
      - Extract player_jump events (tick, steamid)
      - Extract player_land events (tick, steamid)
      - Match jumps and lands for the same player
      - Flight time (ticks) = land_tick - jump_tick
      - Validate at least 5 jump sequences, else raise FeatureExtractionError("insufficient_jumps")

   b. Jump-land timing analysis (per checker requirement):
      - Flight time distribution analysis
      - Legitimate players: variable flight times (0-2 seconds, ~0-128 ticks)
      - Bots: consistent flight times (perfect jump timing every 5-10 ticks)
      - Measure: coefficient of variation (CV) = std(flight_times) / mean(flight_times)
      - CV threshold: < 0.2 = consistent (suspicious)
      - Normalize: use sigmoid_normalize(cv_value, inflection_point=0.2, scale=20.0)

   c. Perfect jump ratio (per checker requirement):
      - Perfect jump = next jump_tick within 2 ticks of previous land_tick
      - Count: perfect_jumps = sum(1 for consecutive pairs if gap <= 2 ticks)
      - Ratio: perfect_jump_ratio = perfect_jumps / total_jumps
      - Perfect jump threshold: > 0.7 = suspicious bhop pattern
      - Normalize: use sigmoid_normalize(perfect_ratio, inflection_point=0.7, scale=5.0)

   d. Sequence length analysis (per checker requirement):
      - Bhop sequences: consecutive jump-land pairs without interruption (gap <= 2 ticks)
      - Count: maximum consecutive sequence length in demo
      - Sequence threshold: > 10 jumps = suspicious (human players land and walk)
      - Normalize: use sigmoid_normalize(max_sequence_length, inflection_point=10, scale=0.2)

   e. Score combination (per checker requirement):
      - final_score = 0.3 * norm_timing_consistency + 0.3 * norm_perfect_ratio + 0.4 * norm_sequence_length
      - Validate with _validate_score()

   f. Return FeatureResult:
      - score: final_score [0.0, 1.0]
      - raw_measurements: {
          "total_jumps": num_jumps,
          "flight_times_ticks": flight_times,
          "flight_time_mean": mean_flight,
          "flight_time_std": std_flight,
          "timing_consistency_cv": cv_value,
          "cv_threshold": 0.2,
          "perfect_jump_ratio": perfect_ratio,
          "perfect_jump_threshold": 0.7,
          "perfect_jump_count": perfect_jumps,
          "max_sequence_length": max_seq_length,
          "sequence_threshold": 10,
          "normalized_cv": norm_cv,
          "normalized_perfect": norm_perfect,
          "normalized_sequence": norm_sequence,
        }
      - metadata: {
          "method": "bhop_timing_sequence_sigmoid",
          "version": "1.0",

        }

3. Quality requirements:
