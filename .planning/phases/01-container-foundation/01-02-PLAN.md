<threat_model>
Trust boundaries:
- HTTP requests enter Nginx and are proxied to PHP-FPM.
- Host bind-mounted Symfony files are executed by PHP.

STRIDE register:
- T-04 Denial of service: Very large uploads can consume local resources. Mitigation: explicit size limits are high enough for demos but visible in config for later tuning.
- T-05 Elevation of privilege: PHP could run as root if Dockerfile omits `USER`. Mitigation: create app UID/GID and switch to `USER app`.
- T-06 Information disclosure: Nginx may serve hidden files. Mitigation: deny dotfiles except `.well-known`.
</threat_model>
