### Task 1: Create useTraceHistoryQuery Hook

**File:** `nextjs/hooks/useTraceHistoryQuery.ts`

**Purpose:** React Query integration for player TRACE history.

**What to build:**

**useTraceHistoryQuery Hook**

```typescript
export function useTraceHistoryQuery(playerId: string, limit: number = 10) {
  return useQuery({
    queryKey: ['traceHistory', playerId, limit],
    queryFn: async () => {
      const response = await fetch(
        `/api/players/${playerId}/trace-history?limit=${limit}&sortBy=date`
      );
      if (!response.ok) {
        throw new Error(`Failed to fetch TRACE history: ${response.statusText}`);
      }
      return response.json() as Promise<TraceHistoryCollectionDto>;
    },
    staleTime: 600000,  // 10 minutes (new demos might come in)
    retry: 1,
    enabled: !!playerId,  // Don't fetch until playerId is available
  });
}
```

**Implementation notes:**
- Type return as `TraceHistoryCollectionDto`
- Throw error on non-200 responses (not 404, endpoint should return empty)
- Use existing React Query client
- Retry once on network errors
- Cache for 10 minutes (shorter than single TRACE, since history changes)
- Only fetch when playerId is truthy

**Definition of Done:**
- Hook works with Wave 1 API
- Returns TraceHistoryCollectionDto type
- Error handling correct
- TypeScript clean
