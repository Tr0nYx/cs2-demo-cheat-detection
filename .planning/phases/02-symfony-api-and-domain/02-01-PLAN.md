<threat_model>
Trust boundaries:
- HTTP traffic enters Symfony through Nginx/PHP-FPM.
- Symfony reads database and Redis connection strings from environment variables.
- Composer dependencies become part of the trusted runtime.

STRIDE register:
- T-02 Information disclosure: Hard-coded credentials could leak in committed config. Mitigation: use environment variables for all service URLs and secrets.
- T-10 Tampering: Overbroad CORS could allow unintended browser clients to call the API. Mitigation: keep CORS local and explicit.
- T-11 Denial of service: Bad service config can keep the app from booting. Mitigation: require container lint and console smoke checks.
</threat_model>
