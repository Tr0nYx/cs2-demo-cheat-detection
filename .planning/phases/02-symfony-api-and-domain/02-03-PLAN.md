<threat_model>
Trust boundaries:
- Untrusted clients upload arbitrary files and query JSON endpoints.
- Uploaded files cross from PHP temporary storage into the demo volume.

STRIDE register:
- T-15 Tampering: Malicious filenames could attempt path traversal. Mitigation: ignore original filename for storage path and use Demo UUID.
- T-16 Denial of service: Oversized uploads could exhaust disk or memory. Mitigation: enforce `MAX_DEMO_UPLOAD_SIZE` and rely on Phase 1 PHP/Nginx limits.
- T-17 Information disclosure: Exception internals could leak through API errors. Mitigation: central error responder with stable public codes.
</threat_model>
