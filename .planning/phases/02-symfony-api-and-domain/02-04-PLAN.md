<threat_model>
Trust boundaries:
- Symfony writes a compact job into Redis for a future Python worker.
- Future Python output or test ingest payloads cross back into Symfony persistence.

STRIDE register:
- T-18 Tampering: Forged result ingest could create false suspicion data. Mitigation: if HTTP ingest exists, require an environment token; otherwise keep ingest internal.
- T-19 Repudiation: Queue failures without cleanup could leave demos stuck forever. Mitigation: upload fails as a whole when queue write fails.
- T-20 Information disclosure: Internal exceptions from Redis/DB could leak through upload errors. Mitigation: stable error envelope and server-side logs only.
- T-21 Denial of service: Oversized ingest payloads could strain the API. Mitigation: validate shape and bound result counts reasonably.
</threat_model>
