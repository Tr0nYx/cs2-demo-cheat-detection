## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API DTO -> presentation view model | Stored result data may be incomplete, aggregate-only, or missing sample facets |
| Feature metadata -> evidence samples | Evidence strings are stored review hints, not proof or complete event reconstruction |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-01 | Tampering | result-dashboard helpers | mitigate | Do not modify scores, verdicts, confidence, TRACE, or thresholds; only add presentation state |
| T-26-02 | Repudiation | context reducers | mitigate | Preserve technical provenance and explicitly show limitations/unavailable states |
| T-26-03 | Information Disclosure | evidence samples | mitigate | Use only existing stored feature evidence; do not infer external profile, rank, or history context |
| T-26-04 | Spoofing | aggregate rows | mitigate | Keep Steam ID 0 and aggregate rows separate from real player attribution |
</threat_model>
