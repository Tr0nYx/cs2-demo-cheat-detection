<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| View model -> review filters | Filters can mislead if they look like threshold changes |
| Compact row UI -> reviewer interpretation | Dense markers can overstate confidence if limitations are hidden |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-05 | Tampering | review filters | mitigate | Implement filters as local display state only; never alter analysis payloads |
| T-26-06 | Repudiation | feature bands | mitigate | Include evidence/capped/unavailable markers alongside score bands |
| T-26-07 | Spoofing | profile links | mitigate | Continue using `profileHref` only and avoid links for placeholders |
| T-26-08 | Denial of Service | dense responsive table | mitigate | Preserve mobile card fallback and stable row dimensions |
</threat_model>
