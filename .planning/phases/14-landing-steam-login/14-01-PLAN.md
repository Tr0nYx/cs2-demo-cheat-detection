<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → API | Unauthenticated requests to `/api/metrics/public` (public data, no PII) |
| Client → External Services | Landing page may link to GitHub (external); no sensitive data sent |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-01 | Information Disclosure | `/api/metrics/public` endpoint | accept | Public metrics contain no PII; aggregated statistics only. Verify backend does not expose user details in metric calculations. |
| T-14-02 | Denial of Service | Public metrics fetch | mitigate | Frontend implements timeout (5 second fetch timeout) and graceful fallback to "Metrics unavailable"; backend rate-limits `/api/metrics/public` if needed (Wave 2+). |
| T-14-03 | Cross-Site Scripting | Hero/Features/Footer text | mitigate | All static text is hardcoded in React components; metrics from API are rendered as plain text (no HTML injection). |

</threat_model>
