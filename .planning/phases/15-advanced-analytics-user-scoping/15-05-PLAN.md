   - __invoke(GetFilteredLeaderboardQuery $query): FilteredLeaderboardDto
   
   - Core ranking SQL:
     ```sql
     WITH player_percentiles AS (
       SELECT 
         tr.player_id,
         PERCENTILE_CONT(0.95) WITHIN GROUP (ORDER BY tr.trace_adjusted) as percentile_95,
         COUNT(*) as demo_count
       FROM trace_rating tr
       JOIN demo d ON tr.demo_id = d.id
       JOIN analysis_result ar ON tr.analysis_result_id = ar.id
       WHERE 1=1
         AND (map IS NULL OR d.map = :map)
         AND (rating_band IS NULL OR calculate_rating_band(tr.trace_adjusted) = :rating_band)
         AND (timeframe IS NULL OR d.analyzed_at >= NOW() - INTERVAL ':timeframe days')
       GROUP BY tr.player_id
       HAVING COUNT(*) >= 5
     ),
     ranked_players AS (
       SELECT 
         p.*,
         pp.percentile_95,
         ROW_NUMBER() OVER (ORDER BY pp.percentile_95 DESC) as rank
       FROM player_percentiles pp
       JOIN player p ON pp.player_id = p.id
     )
     SELECT * FROM ranked_players
     WHERE rank BETWEEN :offset AND :offset + :limit
     ORDER BY rank ASC
     ```
   
   - Helper function calculate_rating_band(float trace_adjusted): string
     * 0-0.33 → '0-5'
     * 0.33-0.67 → '5-10'
     * 0.67+ → '10+'
     * Return as SQL CASE expression or computed before query
   
   - Filter application:
     * map: IF map !== null, add WHERE d.map = :map
     * ratingBand: Map to trace_adjusted percentile bands (same logic as Wave 1)
     * timeframedays: IF timeframe !== null AND < 999, add WHERE d.analyzed_at >= cutoff
     * limit: LIMIT :limit OFFSET :offset
   
   - Return FilteredLeaderboardDto:
     * players: array<PlayerLeaderboardEntryDto>
     * total: int (total qualified players, not just page)
     * hasMore: bool

3. DTO: PlayerLeaderboardEntryDto

     * playerId: string
     * username: string
     * avatar: string | null
     * percentile95: float (95th percentile TRACE score)
     * demoCount: int (for qualification badge)

4. Anti-pattern avoidance (per Pitfall 3 from 15-RESEARCH.md):
