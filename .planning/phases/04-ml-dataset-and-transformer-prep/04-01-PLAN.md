<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HuggingFace API | External dataset source; credentials (HF_TOKEN) must be kept in .env, never hardcoded |
| Filesystem | Demo files and trained models stored locally; no trust required for access but file paths must be validated |
| Environment variables | Configuration (HF_TOKEN, paths, seeds) read from .env; malicious .env can inject arbitrary values |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | .env file with HF_TOKEN | mitigate | Never commit .env; use .env.example as template; add to .gitignore (Wave 5) |
| T-04-02 | Information Disclosure | HF_TOKEN in logs | mitigate | Never log HF_TOKEN or raw config values; redact in debug output |
| T-04-03 | Denial of Service | Large dataset download without quota | accept | Users responsible for HF_TOKEN quota; early failure with clear error message |
| T-04-04 | Tampering | Trained model artifacts from untrusted source | accept | Models stored in version-controlled data/models/; no external model loading in v1 |
| T-04-05 | Information Disclosure | Feature values in logs | mitigate | Log only aggregate statistics (mean, variance); never log individual feature vectors |

</threat_model>
