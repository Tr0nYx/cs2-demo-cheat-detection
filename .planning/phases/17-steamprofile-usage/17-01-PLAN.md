# 17-01-PLAN: Steam Snapshot Data Model

<objective>
Create auditable, versioned storage for Steam profile, inventory, and market-price metadata without mixing external account data into demo-derived detection feature tables.

Covers decisions: D-01, D-02, D-03, D-04, D-05, D-15, D-16.
</objective>

<task>
  <id>17-01-01</id>
  <title>Add Steam profile snapshot entity</title>
  <type>implementation</type>
  <files>
    - symfony/src/Domain/Steam/SteamProfileSnapshot.php
    - symfony/src/Infrastructure/Persistence/SteamProfileSnapshotRepository.php
  </files>
  <action>
    Add a Doctrine entity keyed by UUID with `steamId`, `fetchedAt`, `source`, `visibilityState`, `personaName`, `avatarUrl`, `profileUrl`, `profileState`, `communityVisibilityState`, `timeCreated`, `lastLogoff`, `rawPublicPayload`, `errorCode`, and `errorMessage`. Keep it append-only/versioned. Add repository helpers for latest-by-Steam-ID and stale-candidate queries.
  </action>
  <acceptance_criteria>
    - Entity stores public profile summary fields and source timestamps.
    - Missing/private/unavailable profiles can be represented without exceptions.
    - Repository can return latest snapshot per Steam ID.
  </acceptance_criteria>
  <verify>
    cd symfony; php bin/phpunit --filter SteamProfileSnapshot
  </verify>
</task>
