# 17-02-PLAN: Steam API Clients and Inventory Valuation

<objective>
Implement isolated Steam profile, inventory, and market-price providers that can fetch public metadata, tolerate private/unavailable data, cache market prices, and produce approximate research-only inventory values.

Covers decisions: D-02, D-03, D-04, D-05.
</objective>

<threat_model>
T-17-02: Steam API rate limits or private inventories could create retry storms or misleading zero values.
Mitigation: classified outcomes, cache-first price lookup, unknown/private states, and no zero-value default for unavailable inventories.
</threat_model>
