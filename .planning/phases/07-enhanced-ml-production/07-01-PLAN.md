  <action>
Create movement sensitivity module and integrate into RecoilExtractor:

1. **Create python/features/patterns/movement_sensitivity.py**
   - Function: apply_movement_sensitivity(spray: np.ndarray, velocity_vector: tuple[float, float]) -> np.ndarray
     - Input: spray = shape (N, 2) with [yaw_delta, pitch_delta], velocity_vector = (vx, vy) player velocity m/s
     - Output: adjusted spray with velocity-induced jitter
     - Logic:
       ```
       # Strafing (AD spam) affects spray accuracy
       # High velocity + aimed spray = suspicious
       # velocity_magnitude = sqrt(vx^2 + vy^2)
       # jitter_factor = velocity_magnitude / max_velocity (e.g., 400 m/s)
       # adjusted_spray = spray * (1 + jitter_factor * 0.1)  # 10% max deviation per unit velocity
       ```
     - Clamp jitter_factor to [0.0, 1.0] (velocity > max_velocity still = 1.0 deviation)
     - Return adjusted spray array

2. **Modify python/features/recoil.py**
   - Extract velocity_vector from demo context windows:
     - In RecoilExtractor.extract(), after extracting burst_ticks:
       ```python
       # Get player velocity at fire tick
       player_state = ticks_df[ticks_df["tick"] == fire_tick]
       velocity_x = player_state['velocity_x'].values[0] if 'velocity_x' in ticks_df.columns else 0.0
       velocity_y = player_state['velocity_y'].values[0] if 'velocity_y' in ticks_df.columns else 0.0
       velocity_vector = (velocity_x, velocity_y)
       ```
   - Call apply_movement_sensitivity() before correlation computation:
     ```python
     spray_adjusted = apply_movement_sensitivity(spray, velocity_vector)
     # Use spray_adjusted for correlation instead of raw spray
     ```
   - Track in raw_measurements:
     ```python
     "movement_sensitivity": {
       "velocity_magnitude": float(velocity_magnitude),
       "jitter_factor": float(jitter_factor),
       "spray_adjusted": spray_adjusted.tolist(),
     }
     ```
   - Update metadata:
     ```python
     "movement_sensitivity_enabled": True,
     "velocity_max_threshold_ms": 400,
     ```

3. **Fallback for missing velocity data:**
   - If velocity_x/velocity_y columns don't exist in ticks_df:
     - Log warning: "Player velocity data not available, skipping movement sensitivity"
     - Use unadjusted spray (velocity_vector = (0, 0))
     - Note in metadata: "movement_sensitivity_available": False

**Integration Rationale:**
- Per 07-CONTEXT §1: "Strafing (AD spam) affects spray accuracy — detect jittery aim + movement combos"
- Movement sensitivity amplifies detection of automated aim + movement combos (common in rage aimbots)
- Conservative approach: if velocity data unavailable, gracefully skip (don't crash)

**Why this jitter formula:**
- velocity_magnitude normalized to [0, 400] m/s (max typical CS2 run speed)
- jitter_factor = [0, 1] proportional to player velocity
- spray deviation = ±10% per unit velocity factor
- Results in up to 10% spray distortion at full velocity

**Testing:**
- Unit test: apply_movement_sensitivity() with known velocity → expected spray deviation
- Integration test: RecoilExtractor with velocity data → raw_measurements includes movement_sensitivity fields

| Boundary | Description |
|----------|-------------|
| CS2CD dataset → Pattern extraction | External dataset, untrusted spray data (may contain errors, outliers) |
