## Objective

Harden docker-compose for production deployment on self-hosted VPS with full observability stack (Prometheus + Grafana + Loki) and GitHub Actions CI/CD pipeline.

**Purpose:** Enable production-grade monitoring, log aggregation, and safe deployments with rollback capability.

**Output:**
- Production-hardened docker-compose.prod.yml with all services (Symfony, Python, PostgreSQL, Redis, Prometheus, Grafana, Loki)
- Prometheus config for metrics scraping from worker and API
- Grafana dashboards for system health and analysis metrics
- Loki config for log aggregation with 30-day retention
- GitHub Actions workflow for CI/CD, automated image builds, and SSH deployment
- Deployment rollback strategy via database migration compatibility

## Context

**Deployment Decision (07-CONTEXT §2):**
- Self-hosted VPS (Linode, Hetzner, etc.)
- Docker Compose production orchestration (same as dev, with prod secrets)
- All services in single Compose file: Symfony, Python, PostgreSQL, Redis, Prometheus, Grafana, Loki
- CI/CD: GitHub Actions → test → build Docker images → push to registry → SSH deploy to VPS
- Rollback: Database migration compatibility (migrations self-heal on revert)

**Observability Decision (07-CONTEXT §3):**
- Prometheus: scrape metrics from Python worker (port 8000/metrics), PHP API, node-exporter
- Grafana: unify metrics in dashboards, no auth required (research tool)
- Loki: aggregate logs from Python worker (stdout), PHP container
- Retention: 30 days
- Alert thresholds: P95 latency > 2s, analysis time > 5min, error rate > 5%, resource > 80%

**Metrics to Track:**
- Request latency (P50, P95, P99 for /api/demos/*)
- Analysis duration (time from dispatch to completion)
- Error rates & types (parse failures, model inference failures, DB errors)
- System resources (CPU, memory, disk)

**Existing Infrastructure:**
- docker-compose.yml (dev): PHP, Nginx, PostgreSQL, Redis, Python worker, Next.js frontend
- .github/workflows/ (if exists): may have unit test workflows
- All services run in Docker, use environment variables for config
