## Objective

Add model versioning to the analysis pipeline with graceful model updates, retry resilience, and persistent version tracking.

**Purpose:** Enable traceability of which model scored each demo, support rollback/debugging by model version, and implement production-safe model updates.

**Output:**
- AnalysisResult entity extended with model_version field
- Database migration for model_version column
- Python worker captures and reports model version on every analysis
- Graceful shutdown handler: finish in-flight, load new model, restart
- Retry backoff for inference failures: 1s, 2s, 4s (max 3 retries)

## Context

**Model Versioning Decision (07-CONTEXT §4):**
- Store version in AnalysisResult.model_version (string): git commit SHA or semantic version (e.g., "v1.0.1-anticheatpt-2026-05-15")
- Every demo records which model scored it
- Queryable for retro-analysis, debugging version-specific issues
- No A/B testing in v1 (single model per deploy)

**Graceful Shutdown (07-CONTEXT §4.2):**
- Worker receives SIGTERM, stops accepting new jobs
- Finishes in-flight analyses (timeout: 5 minutes max)
- Loads new model
- Restarts (no downtime if possible)
- Typical downtime: 1-2 minutes

**Inference Failure Handling (07-CONTEXT §4.3):**
- Retry with exponential backoff: 1s, 2s, 4s (max 3 retries)
- If all retries fail: mark demo as error, user can retry later
- No fallback to heuristics (fail explicitly for reproducibility)

**Backwards Compatibility:**
- New model must accept same input schema as old
- If schema changes, write adapter in deployment script
- No migration of old analysis results to new schema

1. **Add shutdown handler to python/worker.py**:
   ```python
   import signal
   import sys
   from typing import Optional

   class DemoAnalysisWorker:
       def __init__(self):
           # ... existing code
           self.shutdown_requested = False
           self.in_flight_analyses = {}
           signal.signal(signal.SIGTERM, self._handle_sigterm)
           logger.info("SIGTERM handler registered")

       def _handle_sigterm(self, signum, frame):
           """Handle SIGTERM gracefully: finish in-flight analyses, then exit."""
           logger.warning("SIGTERM received, initiating graceful shutdown...")
           self.shutdown_requested = True

       def _should_accept_new_jobs(self) -> bool:
           """Return False if shutdown requested."""
           return not self.shutdown_requested

       def run(self):
           """Main worker loop."""
           while True:
               if self.shutdown_requested:
                   logger.info("Shutdown requested, finishing in-flight analyses...")
                   self._wait_for_in_flight()
                   logger.info("All in-flight analyses completed. Exiting.")
                   sys.exit(0)

               if not self._should_accept_new_jobs():
                   # Skip job retrieval, just check in-flight status
                   time.sleep(1)
                   continue

               # Get next job from queue (only if accepting jobs)
               job = self._get_next_job_from_queue(timeout=self.poll_timeout)
               if job is None:
                   continue

               # Track in-flight analysis
               demo_id = job["demo_id"]
               self.in_flight_analyses[demo_id] = {
                   "start_time": time.time(),
                   "job": job,
               }

               try:
                   # Run analysis
                   result = self._analyze_demo(job)
                   self._send_result_to_api(result)
               except Exception as e:
                   logger.error(f"Analysis failed for demo {demo_id}: {e}")
               finally:
                   # Remove from in-flight
                   del self.in_flight_analyses[demo_id]

       def _wait_for_in_flight(self, timeout_seconds=300):
           """Wait for all in-flight analyses to complete."""
           start = time.time()
           while self.in_flight_analyses and (time.time() - start) < timeout_seconds:
               remaining = len(self.in_flight_analyses)
               logger.info(f"Waiting for {remaining} in-flight analyses to complete...")
               time.sleep(1)

           if self.in_flight_analyses:
               # Timeout reached, log and continue (don't wait forever)
               logger.warning(f"Shutdown timeout reached, {len(self.in_flight_analyses)} analyses still in flight")
               # Option: send error results for in-flight demos, or just exit
               for demo_id in list(self.in_flight_analyses.keys()):
                   logger.error(f"Abandoning in-flight analysis: {demo_id}")
                   del self.in_flight_analyses[demo_id]
   ```

Implement retry logic for model inference failures (per 07-CONTEXT §4.3):

1. **Create retry decorator/utility in python/ml/model.py**:
   ```python
   import time
   from functools import wraps

   def retry_with_backoff(max_retries=3, backoff_factor=1.0):
       """Decorator for exponential backoff retry."""
       def decorator(func):
           @wraps(func)
           def wrapper(*args, **kwargs):
               for attempt in range(max_retries):
                   try:
                       return func(*args, **kwargs)
                   except Exception as e:
                       if attempt == max_retries - 1:
                           # Last attempt failed, raise
                           raise
                       
                       wait_time = (2 ** attempt) * backoff_factor  # 1s, 2s, 4s
                       logger.warning(
                           f"Inference failed (attempt {attempt + 1}/{max_retries}): {e}. "
                           f"Retrying in {wait_time}s..."
                       )
                       time.sleep(wait_time)
           return wrapper
       return decorator
   ```

2. **Apply retry to model inference in DemoAnalysisWorker**:
   ```python
   @retry_with_backoff(max_retries=3, backoff_factor=1.0)
   def _run_model_inference(self, context_tensor) -> np.ndarray:
       """Run model inference with automatic retry on failure."""
       try:
           with torch.no_grad():
               output = self.model(context_tensor)
           return output.cpu().numpy()
       except RuntimeError as e:
           # Model inference error (OOM, device failure, etc.)
           logger.error(f"Model inference error: {e}")
           raise
       except Exception as e:
           # Any other error during inference
           logger.error(f"Unexpected inference error: {e}")
           raise

   def _analyze_demo(self, job: dict) -> dict:
       """Analyze demo with retry-enabled inference."""
       demo_id = job["demo_id"]
       file_path = job["file_path"]

       try:
           # Parse demo (no retry)
           parsed_demo = self.parse_demo(file_path)

           # Extract features (no retry)
           features = self.extract_features(parsed_demo)

           # Run inference with retries
           scores = self._run_model_inference(features)

           result = {
               "demo_id": demo_id,
               "scores": scores.tolist(),
               "model_version": self.model_version,
               "status": "success",
           }
       except Exception as e:
           logger.error(f"Demo analysis failed after retries: {demo_id}, error: {e}")
           result = {
               "demo_id": demo_id,
               "status": "error",
               "error_message": f"Inference failed after 3 retries: {str(e)[:200]}",
               "model_version": self.model_version,
           }

       return result
   ```

3. **Track retry metrics (Prometheus)**:
   ```python
   from prometheus_client import Counter

   inference_retries = Counter(
       'model_inference_retries_total',
       'Total inference retry attempts',
       ['demo_id', 'attempt']
   )

   # In retry wrapper:
   ```

4. **Handle specific failure scenarios**:
   - **Timeout**: If inference > 60 seconds, assume hang, retry (timeout should be enforced at model level)
   - **OOM**: Model inference out of memory → log, retry (may fail again if not freed)
   - **Device failure**: CUDA device unavailable → mark error, don't retry (hardware issue)
   - **Bad input**: Invalid tensor shape → mark error, don't retry (data issue)

5. **Logging**:
   - Log each retry attempt with backoff time
   - Log final failure with full error message
   - Don't leak PII (demo file paths OK, but not model weights)

**Backoff schedule:**
- Attempt 1: Immediate (0 retries yet)
- Attempt 2: Wait 1 second (2^0 = 1)
- Attempt 3: Wait 2 seconds (2^1 = 2)
- Attempt 4: Wait 4 seconds (2^2 = 4)
- Max 3 retries = up to 7 seconds total wait

**Why no fallback to heuristics:**
- Per 07-CONTEXT §4.3: "No fallback to heuristics (v1 Phase 7) — fail explicitly for reproducibility"
- Fallback would make results non-reproducible (sometimes ML, sometimes rule-based)
- Better to fail and let user retry later

**Integration:**
- Inference failures automatically retry without human intervention
- User sees result after success or final failure (either way they get a result)
- Model inference reliability improves without code complexity

**Testing:**
- Unit test: retry decorator succeeds on 2nd attempt
- Unit test: retry decorator fails after max retries
- Integration test: simulate inference failure, verify retries and eventual success/failure
