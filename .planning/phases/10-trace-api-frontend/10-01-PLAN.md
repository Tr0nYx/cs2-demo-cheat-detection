# Phase 10 PLAN: Wave 1 — TRACE API Endpoint

**Objective**

Expose TRACE rating data via REST API endpoint. Wave 1 creates the JSON API layer (DTOs, mapper, controller) and tests to enable frontend and external consumers to query TRACE scores per demo.

**Purpose:** Clients (frontend, third-party APIs) can retrieve TRACE breakdown, calibration version, and component scores with a single HTTP call.

**Deliverable:** Production-ready API endpoint with full error handling, type hints, and integration tests.

## Task Details

### Task 1: Create DTOs for TRACE Data

**Files:**
- `symfony/src/Application/DTO/TraceDto.php`
- `symfony/src/Application/DTO/TraceComponentDto.php`

**Purpose:** Define serializable data structures for TRACE response.

**What to build:**

**TraceComponentDto** (sub-DTO for individual component scores)
```
properties:
  - ekill: float (normalized [0.3, 2.0])
  - aim: float (normalized [0.3, 2.0])
  - kast: float (normalized [0.3, 2.0])
  - util: float (normalized [0.3, 2.0])
  - clutch: float (normalized [0.3, 2.0])
```

**TraceDto** (main response DTO)
```
properties:
  - traceBase: float (unweighted average before adjustment)
  - traceAdjusted: float (base × trust_multiplier)
  - traceNormalized: float (adjusted / calibration.global_average)
  - trustMultiplier: float (clamped [0.73, 1.00], from D-06)
  - components: TraceComponentDto (ekill, aim, kast, util, clutch)
  - calibrationVersion: string (e.g., "default-v1", "live-v1")
  - calculatedAt: DateTimeImmutable (ISO 8601)
  - createdAt: DateTimeImmutable (when stored)
```

**Implementation notes:**
- Use Symfony Serializer attributes (#[Serializer\Groups(...)])
- Type hints on all properties
- Docstring explaining value ranges
- Follow AnalysisResultDto pattern (camelCase properties)
- Immutable properties (readonly if possible)
- No methods except getters

**Definition of Done:**
- Both DTOs exist with all required properties
- Type hints on all public properties/methods
- Docstrings present
- Serializable (Symfony serializer can convert to JSON)
- No logic (data containers only)

### Task 2: Create Mapper from Entity to DTO

**File:** `symfony/src/Application/Mapper/TraceMapper.php`

**Purpose:** Convert TraceRating entity to TraceDto for API response.

**What to build:**

**TraceMapper Class**

Method:
```php
public function toDto(TraceRating $traceRating, TraceCalibration $calibration = null): TraceDto
```

**Logic:**
1. Create TraceComponentDto from entity properties (ekill, aim, kast, util, clutch)
2. Create TraceDto with:
   - traceBase: from $traceRating->getTraceBase()
   - traceAdjusted: from $traceRating->getTraceAdjusted()
   - traceNormalized: from $traceRating->getTraceNormalized()
   - trustMultiplier: from $traceRating->getTrustMultiplier()
   - components: TraceComponentDto
   - calibrationVersion: from $traceRating->getCalibrationVersion()
   - calculatedAt: from $traceRating->getCalculatedAt()
   - createdAt: from $traceRating->getCreatedAt()
3. Return TraceDto

**Error handling:**
- If entity missing required properties: log warning, skip (non-fatal)
- If calibration null: that's OK, use calibration_version string from entity

**Definition of Done:**
- Mapper exists with toDto() method
- Converts all fields without data loss
- Type hints on method signature
- Docstring explaining inputs/outputs
- No breaking changes

### Task 3: Create TraceController with GET Endpoint

**File:** `symfony/src/Presentation/Controller/TraceController.php`

**Purpose:** Handle HTTP GET requests for TRACE data.

**What to build:**

**TraceController Class**

Dependency injection:
- TraceRatingRepository
- TraceCalibrationRepository
- TraceMapper
- AnalysisResultRepository (to validate demo exists)

Route:
```php
#[Route('/api/demos/{id}/trace', name: 'get_trace', methods: ['GET'])]
public function getTrace(string $id, ...): Response
```

**Handler logic:**
1. Parse `{id}` as demoId (UUID or bigint depending on schema)
2. Query AnalysisResultRepository.findById($id)
   - If not found: return 404 with message "Demo not found"
3. Query TraceRatingRepository.findByAnalysisResultId($id)
   - If not found: return 404 with message "TRACE not yet calculated for this demo"
4. Load TraceCalibration by version (for context, optional)
5. Use TraceMapper.toDto() to convert entity → DTO
6. Return JSON response with 200, DTO as body

**Error handling:**
- Invalid UUID/ID format: return 400 "Invalid demo ID"
- Database errors: log, return 500 "Internal server error"
- Missing entity: return 404 (not 500)

**Response headers:**
- Content-Type: application/json
- Cache-Control: public, max-age=3600 (TRACE immutable once calculated)

**Type hints:**
- All parameters typed
- Return type: JsonResponse or Response

**Docstring:**
- Explains endpoint purpose, parameters, return codes

**Definition of Done:**
- Controller exists with getTrace() method
- Route registered and accessible via HTTP
- All error codes (200, 400, 404, 500) handled
- Type hints on all public methods
- Docstring present

## Threat Model & Mitigations

| Threat ID | Category | Component | Mitigation |
|-----------|----------|-----------|-----------|
| T-10-01-01 | Information Disclosure | TRACE endpoint | Endpoint returns only TRACE (not PII). Access control to API enforced by existing AnalysisResult auth. |
| T-10-01-02 | Denial of Service | Query performance | Repository finder uses indexed queries. Cache-Control header enables CDN caching. Rate limiting deferred to API gateway. |
| T-10-01-03 | Tampering | DTO serialization | DTOs are immutable, no setters. Mapper reads from trusted entity. |
