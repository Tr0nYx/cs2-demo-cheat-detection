**Method 1: findQualifiedByMapAndSorted(string $mapId, int $limit, int $offset): array**
Purpose: Return qualified players for specific map, sorted by trace_adjusted descending

DQL implementation (assuming Demo.map exists):
```php
public function findQualifiedByMapAndSorted(
    string $mapId,
    int $limit = 100,
    int $offset = 0
): array {
    return $this->createQueryBuilder('tr')
        ->select('tr')
        ->innerJoin('tr.analysisResult', 'ar')
        ->innerJoin('ar.demo', 'd')
        ->where('d.map = :mapId')
        ->andWhere('(SELECT COUNT(tr2.id) FROM TraceRating tr2 WHERE tr2.playerId = tr.playerId) >= 5')
        ->setParameter('mapId', $mapId)
        ->orderBy('tr.traceAdjusted', 'DESC')
        ->setFirstResult($offset)
        ->setMaxResults($limit)
        ->getQuery()
        ->getResult();
}
```

**Method 2: findQualifiedByTimeWindowAndSorted(int $daysBack, int $limit, int $offset): array**
Purpose: Return qualified players for demos analyzed in last N days (global qualification applied)

Implementation:
```php
public function findQualifiedByTimeWindowAndSorted(
    int $daysBack,
    int $limit = 100,
    int $offset = 0
): array {
    $cutoffDate = new \DateTimeImmutable('-' . $daysBack . ' days');

    return $this->createQueryBuilder('tr')
        ->select('tr')
        ->where('tr.calculatedAt >= :cutoff')
        ->andWhere('(SELECT COUNT(tr2.id) FROM TraceRating tr2 WHERE tr2.playerId = tr.playerId AND tr2.calculatedAt >= :cutoff) >= 5')
        ->setParameter('cutoff', $cutoffDate, \Doctrine\DBAL\Types\Types::DATETIME_IMMUTABLE)
        ->orderBy('tr.traceAdjusted', 'DESC')
        ->setFirstResult($offset)
        ->setMaxResults($limit)
        ->getQuery()
        ->getResult();
}
```

**Critical:** Use DATE_TRUNC or calculated_at >= cutoff to handle timezone-aware filtering. Store all timestamps in UTC.

| T-12-06 | Denial of Service | /api/leaderboards/windows/{timeWindow} | mitigate | Whitelist timeWindow to enum values (30d, 90d); return 400 for other values; validate limit, offset |
