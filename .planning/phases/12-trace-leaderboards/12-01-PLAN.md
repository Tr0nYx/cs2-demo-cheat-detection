**Method 1: findQualifiedAndSorted(int $limit, int $offset): array**
Purpose: Return qualified players (5+ demos) sorted by trace_adjusted descending for global leaderboard

DQL implementation:
```php
public function findQualifiedAndSorted(int $limit = 100, int $offset = 0): array
{
    return $this->createQueryBuilder('tr')
        ->select('tr')
        ->where('(SELECT COUNT(tr2.id) FROM TraceRating tr2 WHERE tr2.playerId = tr.playerId) >= 5')
        ->orderBy('tr.traceAdjusted', 'DESC')
        ->setFirstResult($offset)
        ->setMaxResults($limit)
        ->getQuery()
        ->getResult();
}
```

Purpose: Return total count of qualified players (for pagination metadata)

public function countQualified(): int

        ->select('COUNT(DISTINCT tr.playerId)')
        ->where('(SELECT COUNT(tr2.id) FROM TraceRating tr2 WHERE tr2.playerId = tr.playerId) >= 5')
        ->getQuery()

public function countByPlayerId(string $playerId): int

        ->getSingleScalarResult();
}

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → API | Leaderboard endpoints accept user input (limit, offset); must validate before query |
| API → Database | Doctrine DQL prevents SQL injection via parameter binding |
| Database → Cache | Leaderboards are public read-only data; no sensitive information |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01 | Denial of Service | LeaderboardController.getGlobalLeaderboard | mitigate | Validate limit (1-100) and offset (>= 0) at controller entry; return 400 Bad Request for invalid params |
| T-12-02 | Information Disclosure | Leaderboard data | accept | Leaderboards are intentionally public (like Steam leaderboards); no authentication required; player IDs are already enumerable via demo analysis results |
| T-12-03 | Tampering | Rank/Score modification | accept | Ranks computed at query time from immutable TraceRating (set at analysis completion); no API endpoint to modify rank or retroactively change TRACE score |
| T-12-04 | Denial of Service | Database query performance | mitigate | Add index on trace_rating(trace_adjusted DESC, player_id) for O(1) top-K retrieval; pagination prevents full-table scans; monitor query time < 200ms |

</threat_model>
