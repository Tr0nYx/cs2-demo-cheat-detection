<objective>
Extend all existing feature extractors (aimbot, wallhack, triggerbot, recoil, bhop) to compute first, second, and third-order derivatives of angles and velocities within their context windows, per AntiCheatPT best practices (D-01 through D-04).

Purpose: Capture temporal acceleration and mechanical snap patterns that traditional single-order measurements miss. Derivatives are computed locally within each extractor's natural granularity (kill-window for aimbot, spray-window for recoil) to preserve player-specific framing.

Output: Modified extractors that return derivative measurements in raw_measurements alongside traditional scores, maintaining backward compatibility for Phase 20 validation.
</objective>

```python
@staticmethod
def _compute_derivatives(values: np.ndarray) -> dict:
    """Compute first, second, third-order derivatives of a value sequence.
    
    Per D-02 and D-03: captures rate of change, acceleration, and jerk.
    Used by temporal extractors (aimbot, wallhack, triggerbot, recoil, bhop).
    
    Args:
        values: Array of measurements over time (e.g., angles, velocities)
    
    Returns:
        Dictionary with first/second/third-order derivative statistics
    """
    if len(values) < 3:
        return {
            "first_order_max": 0.0,
            "first_order_mean": 0.0,
            "second_order_max": 0.0,
            "second_order_mean": 0.0,
            "third_order_max": 0.0,
            "third_order_mean": 0.0,
        }
    
    # Compute derivatives using np.gradient (standard numpy)
    first = np.gradient(values)
    second = np.gradient(first)
    third = np.gradient(second)
    
    # Summarize using max and mean of absolute values
    return {
        "first_order_max": float(np.max(np.abs(first))),
        "first_order_mean": float(np.mean(np.abs(first))),
        "second_order_max": float(np.max(np.abs(second))),
        "second_order_mean": float(np.mean(np.abs(second))),
        "third_order_max": float(np.max(np.abs(third))),
        "third_order_mean": float(np.mean(np.abs(third))),
    }
```

This method is called by all temporal extractors in subsequent tasks.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Parser → Features | Derivative computation assumes tick/event data from parser is valid; no injection of synthetic data at this stage |
| Features → Scoring | Raw measurements (including derivatives) are passed to WeightedScorer, which applies Phase 20 gates before visible scores |
| Visible Output | Derivative data is internal raw_measurements only; visible score remains subject to calibration and evidence gates |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-01 | Tampering | Derivative computation overflow/NaN | mitigate | np.gradient handles standard numeric ranges; add validation that derivative arrays contain finite values before storing in raw_measurements |
| T-22-02 | Information Disclosure | Raw derivative data exposed in API | mitigate | Derivative data stored in raw_measurements for explainability (research-safe); frontend displays only if explicitly requested in evidence view; API contract unchanged |
| T-22-03 | Tampering | Augmentation leakage into production | accept-for-wave-1 | Wave 1 adds derivatives only; augmentation pipeline (Wave 3) implements is_training flag to prevent production contamination |
