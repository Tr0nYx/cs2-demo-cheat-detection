<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Viewer API | Query params are user controlled |
| Viewer API -> Database | Event lookup must be read-only and bounded |
| Viewer API -> Redis | Tick cache values are internal but can be absent/corrupt |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-05 | Denial of Service | events endpoint | mitigate | Validate filters, paginate/limit if needed, indexed demo/tick/round columns |
| T-13-06 | Information Disclosure | event response | mitigate | Return gameplay telemetry only for uploaded demos; no secrets or ingest tokens |
| T-13-07 | Tampering | Redis cache | mitigate | Treat cache as derived data; decode failures are misses/errors, not trusted writes |
| T-13-08 | Repudiation | suspicion response | mitigate | Include metric/reason fields and avoid proof/enforcement language |
</threat_model>
