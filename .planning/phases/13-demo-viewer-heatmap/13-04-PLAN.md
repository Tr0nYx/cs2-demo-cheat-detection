<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> tick endpoint | User controls range, filters, and step |
| Frontend hooks -> browser memory | Large tick payloads can harm UX |
| API -> Redis cache | Redis chunk may be absent or corrupt |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-13 | Denial of Service | tick endpoint | mitigate | Range caps, step validation, chunking, 202 on cache miss |
| T-13-14 | Information Disclosure | ticks response | accept | Post-game demo telemetry is the product output |
| T-13-15 | Denial of Service | useTickData | mitigate | Chunked fetch, adjacent prefetch only, no full-demo eager load |
| T-13-16 | Tampering | map transform constants | mitigate | Unit parity tests with Python known values |
</threat_model>
