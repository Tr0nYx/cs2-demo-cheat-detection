<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Analysis result -> review UI | Suspicion metrics can be misinterpreted by users |
| Client interactions -> playback state | User-selected event seeks affect UI state only |
| Grenade event data -> inspector | Trajectories are derived from parsed demo events |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-21 | Repudiation | SuspicionPanel | mitigate | Show metric reasons and label as review signal, not proof |
| T-13-22 | Information Disclosure | GrenadeInspector | accept | Post-game utility trajectories are intended analysis output |
| T-13-23 | Denial of Service | similar throws | mitigate | Client-side over already-loaded event list or bounded endpoint query |
| T-13-24 | Tampering | event summaries | mitigate | Upsert from trusted analysis/export pipeline only; no public mutation endpoint |
</threat_model>
