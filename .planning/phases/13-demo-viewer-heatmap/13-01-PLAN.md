<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Demo file -> Python parser | Uploaded demo is untrusted binary input parsed post-game only |
| Python -> Redis | Tick chunks and heatmap jobs are internal cache artifacts |
| Python -> filesystem | Heatmap renderer reads radar assets and later writes generated PNGs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-01 | Denial of Service | tick_exporter | mitigate | Enforce positive `step`, chunk size, and bounded chunk writes |
| T-13-02 | Tampering | map_config | mitigate | Unit tests for known transforms; no runtime external map config in this wave |
| T-13-03 | Information Disclosure | Redis tick cache | mitigate | Store only post-game demo telemetry, TTL 48h, no secrets |
| T-13-04 | Denial of Service | heatmap renderer | mitigate | Configurable sigma, direct array bounds checks, tests for empty events |
</threat_model>
