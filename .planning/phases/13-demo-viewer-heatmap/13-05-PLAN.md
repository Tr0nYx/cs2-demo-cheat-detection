<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API -> Browser | Demo telemetry is rendered client-side |
| Canvas renderer -> UI thread | Large frames can affect responsiveness |
| Heatmap image -> Browser | PNG URL uses user-selected filters |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-17 | Denial of Service | MapCanvas | mitigate | Canvas loop only, memoized tick lookup, no per-tick DOM |
| T-13-18 | Information Disclosure | viewer UI | accept | Product intentionally displays post-game telemetry |
| T-13-19 | Spoofing | radar asset path | mitigate | Use fixed public map asset path derived from validated map names |
| T-13-20 | Denial of Service | HeatmapViewer | mitigate | Stable image element, no repeated polling loop without user action |
</threat_model>
