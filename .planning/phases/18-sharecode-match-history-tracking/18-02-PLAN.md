# 18-02-PLAN: User-Scoped Tracking API

<objective>
Expose authenticated API endpoints that let a logged-in Steam user connect match-history tracking, read minimal status, and disconnect tracking while enforcing same-user Steam identity and never exposing the stored `steamidkey`.

<threat_model>
T-18-03: A user could try to track another user's match history by supplying a different Steam ID.
Mitigation: derive Steam ID only from the authenticated session/JWT and never accept `steamid` from request body for normal users.

T-18-04: API responses could accidentally expose `steamidkey` or ciphertext.
Mitigation: dedicated safe DTO, tests asserting absent secret fields, and controller never serializes the entity directly.
</threat_model>
