<threat_model>
T-18-01: The stored Steam Game Authentication Code could leak through database dumps, logs, errors, API responses, or test fixtures.
Mitigation: encrypt at rest with env-provided key, never serialize plaintext, test ciphertext/fingerprint behavior, and avoid logging request query parameters that include `steamidkey`.

T-18-02: Incorrect Valve status mapping could cause aggressive invalid-credential retries and temporary API blocking.
Mitigation: typed client results, explicit `403`/`412` terminal states, `429`/`503` backoff states, and tests for all documented statuses.
</threat_model>
